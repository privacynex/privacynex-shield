# Security policy

## Supported version

Only the latest published release receives security fixes.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue.

Send a private report through GitHub Security Advisories for `privacynex/privacynex-shield`. Include the affected version, reproduction steps, impact and any suggested mitigation.

Never include real production secrets, personal data or unrelated third-party data in a report.

## Scope

The project covers the Privacynex Shield source, its exported Fetch middleware and the provided Cloudflare Pages scaffold. Other platform adapters, account configuration, WAF rules and applications embedding the package remain the operator's responsibility.
